# Bug bounty mode

Read the approved program scope, out-of-scope exclusions, rate limits, data handling and disclosure rules into `.ctx/SCOPE.md` from authoritative sources. Do not assume a domain or endpoint is in scope. Focus on smallest reproducible proof, observed impact, authentication context, and test safety. Treat hypothetical impact as unverified. Keep sensitive data out of persistent notes. Before reporting, cross-check reproducibility, false positives and policy restrictions. Record rejected paths to avoid repeated tests.
